## Critical Gaps to Production Readiness

### P0 — Must Fix Before Launch (Users Will Hit These)

1. **No email alert system wired** — Competitor alerts, citation drift alerts, AI visibility change alerts are all detected but never emailed. The cron runs, data updates, but the user never knows unless they check the dashboard.
   - Fix: Wire Resend email sending into the cron routes when changes are detected.

2. **No 14-day trial logic** — Pricing says "Start 14-Day Trial" but Stripe checkout creates a paid subscription immediately.
   - Fix: Add trial_period_days=14 to Stripe checkout session creation.

3. **No annual billing in Stripe** — Toggle exists on pricing page, annual price IDs are in .env, but checkout may not respect the annual flag.
   - Fix: Verify checkout route switches between monthly/annual price IDs based on selection.

4. **AI Overview shows "Simulated" without real API keys** — This is the hero feature and users on Free/Starter see simulated results.
   - Fix: Configure at minimum PERPLEXITY_API_KEY and OPENAI_API_KEY for real ChatGPT simulation. Or be honest about which engines are live vs simulated in the UI.

5. **Competitor data is mock when no Google Maps key** — Every new user sees fake competitors.
   - Fix: Make GOOGLE_MAPS_API_KEY a required env var, or clearly label mock data with "Add your Google API key for real competitors."

6. **No onboarding flow after signup** — User signs up, lands on dashboard, nothing guides them to run their first scan.
   - Fix: Onboarding page exists but needs to auto-trigger for new users.

### P1 — Should Fix Before Public Launch

7. **GBP Posts can't actually publish to Google** — Templates and post creation work, but no actual Google Business Profile API publish call.
   - Fix: Wire the GBP API publish call using the stored OAuth token.

8. **"Will AI Assistant" chat is a stub** — Pricing says it's included, but `/api/chat` likely returns an error or generic response.
   - Fix: Wire to OpenAI with scan context as system prompt.

9. **No PDF report branding/white-label** — Growth says "Branded", Authority says "White-label" but both produce the same PDF.
   - Fix: Add branding parameters to report generation, check plan tier.

10. **No multi-location switching** — Authority plan ($297) says "multi-location" but there's no location switcher UI.
    - Fix: Add location selector to sidebar, scope all data queries by selected location.

11. **No developer API documentation** — Public API works but there's no docs page, no examples, no SDK.
    - Fix: Build `/api/docs` page with endpoint reference and code examples.

12. **Dashboard is mostly empty on first visit** — No sample data, no guided tour, no "run your first scan" prompt prominent enough.
    - Fix: Show empty states with clear CTAs, pre-populate with a sample scan.

### P2 — Nice to Have for Launch

13. **Email journey steps aren't triggered by real events** — Journey is configured but steps aren't tied to actual user actions (e.g., "you ran your first scan" email doesn't fire).
14. **No rate limiting on public endpoints** — API key-authenticated endpoints have no rate limiting.
15. **No data export** — Users can't export their scan history, citations, or reports as CSV.
16. **No webhook/callback system** — No way for users to receive programmatic notifications about changes.
17. **Mobile responsive gaps** — Some feature pages (AI visibility, trust score) aren't fully responsive on mobile.
18. **No error boundary** — API failures in frontend don't have graceful error states everywhere.
